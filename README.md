# Customer Segmentation with RFM Analysis

## Описание проекта

Сегментация клиентов интернет-магазина на основе их покупательского поведения с использованием RFM-анализа (Recency, Frequency, Monetary) и кластеризации KMeans.

## Бизнес-задача

Интернет-магазин хочет персонализировать маркетинговые кампании. Вместо того чтобы предлагать всем одинаковые скидки, необходимо выделить группы клиентов с похожим поведением и для каждой группы разработать свою стратегию.

##  Данные

- **Источник:** Online Retail Dataset (Kaggle/UCI)
- **Объём:** 541 909 транзакций
- **Период:** 01.12.2010 — 09.12.2011 (373 дня)
- **Колонки:** InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country

##  Методы

1. **EDA** — разведочный анализ данных
2. **Очистка данных** — удаление пропусков, дубликатов, возвратов
3. **Feature Engineering** — создание TotalPrice = Quantity × UnitPrice
4. **RFM-анализ** — расчёт Recency, Frequency, Monetary для каждого клиента
5. **Масштабирование** — StandardScaler (KMeans чувствителен к масштабу)
6. **Кластеризация** — KMeans с K=3 (выбрано по методу локтя)

### Бизнес-рекомендации

- **Кластер 0 (Активные покупатели):** Программа лояльности, бонусы за повторные покупки, email-рассылки.
- **Кластер 1 (Редкие покупатели):** Персонализированные предложения, напоминания, акции для возврата клиентов.
- **Кластер 2 (VIP-клиенты):** Персональный менеджер, эксклюзивные предложения, бесплатная доставка, ранний доступ к новинкам.
